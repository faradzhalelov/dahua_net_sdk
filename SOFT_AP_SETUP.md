# Настройка камеры через Soft AP (первичная конфигурация)

## Назначение

Эта функция используется для первичной настройки камеры, когда она ещё не подключена к WiFi сети.

## Принцип работы

1. **Камера создаёт свою WiFi точку доступа (Soft AP)** с именем типа `DHIPC-XXXXXX`
2. **Пользователь подключается** к этой точке доступа с телефона
3. **Приложение сканирует** доступные WiFi сети через камеру
4. **Пользователь выбирает** свою домашнюю WiFi сеть из списка
5. **Вводит пароль** от WiFi и серийный номер камеры
6. **Приложение отправляет** данные камере через звук (FSK модуляция)
7. **Камера подключается** к домашней WiFi сети
8. **Приложение находит** камеру в сети и отображает её параметры

## Использование в приложении

### 1. Подключение к камере

- Зайдите в настройки WiFi на телефоне
- Найдите сеть с именем `DHIPC-` или `DH-IPC-`
- Подключитесь к этой сети (пароль обычно не требуется)

### 2. Настройка в приложении

1. Откройте экран **"Soft AP WiFi Setup"**
2. Проверьте IP адрес камеры (обычно `192.168.1.1` или `192.168.80.1`)
3. Нажмите **"Сканировать WiFi сети"**
4. Дождитесь окончания сканирования
5. Выберите свою домашнюю WiFi сеть из выпадающего списка
6. Введите серийный номер камеры
7. Введите пароль от WiFi
8. Нажмите **"Начать конфигурацию"**

### 3. Процесс конфигурации

Приложение будет:
- Отправлять WiFi данные камере через звук (не выключайте звук!)
- Искать камеру в домашней сети
- Показывать статус в реальном времени

### 4. Успешная настройка

После успешной настройки вы увидите:
- IP адрес камеры в домашней сети
- MAC адрес
- Порт подключения
- Серийный номер

## Возможные проблемы

### WiFi сети не найдены

- Проверьте IP адрес камеры (попробуйте `192.168.80.1` вместо `192.168.1.1`)
- Убедитесь, что телефон подключён к Soft AP камеры
- Проверьте, что камера находится рядом с WiFi роутером

### Камера не найдена после настройки

- Проверьте правильность пароля WiFi
- Убедитесь, что SSID введён без ошибок (используйте выбор из списка!)
- Проверьте, что телефон подключён к той же WiFi сети
- Подождите 30-60 секунд для подключения камеры

### Ошибка отправки данных

- Убедитесь, что звук на телефоне включён и громкость достаточная
- Поднесите телефон ближе к камере
- Попробуйте ещё раз

## Безопасность

- Пароль WiFi передаётся через защищённый FSK канал
- Данные шифруются на уровне SDK
- После настройки Soft AP режим автоматически отключается
